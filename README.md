# Kolmar 2026 OpenLab Showcase

콜마 2026 OpenLab에서 다루는 업무 자동화 아이디어를 발표와 웹에서 보여주기 위한 공개 쇼케이스입니다.

- 공개 사이트: [alsrl8.github.io/kolmar-2026-openlab-showcase](https://alsrl8.github.io/kolmar-2026-openlab-showcase/)
- 발표 조작: 화면 클릭, 좌우 방향키, Page Up/Down 또는 Space로 이동하며 영상 슬라이드는 진입 즉시 재생됩니다.

## 공개 범위

이 저장소에는 공개 검토를 마친 자료만 둡니다.

- 웹 발표용 HTML
- 발표에 삽입할 MP4 영상
- 영상의 정적 대표 이미지
- 공개 발표에 필요한 스타일과 빌드 설정

고객 원본, 개인정보, 내부 연락처, 인증정보, 비공개 분석 문서와 실제 업무 데이터는 포함하지 않습니다.

## 관리 구조

공개 자료는 다음 경로를 사용합니다.

```text
presentation/        웹 발표 소스
public/videos/       공개 승인된 MP4
public/posters/      영상별 정적 대표 이미지
public/assets/       공개 발표용 스타일과 이미지
```

## 현재 공개 자료

- 물류팀(부천): 명세서 저장,분류,전달 프로세스 자동화 · 2개 phase
- 스케일업팀: 신제품 개발 프로세스 단계별 알람 자동화 · 2개 phase
- 품질보증팀: 원료명 및 시험규격 변경관리 프로세스 자동화 · 3개 phase
- 품질관리2팀: AI 기반 분석 리스트 작성과 누락 방지 · 2개 phase
- 품질관리4팀: 미생물 시험 데이터와 재시험 관리 · 3개 phase
- 품질관리4팀: n8n을 통한 미생물 업무 자동화 · 3개 phase

표지와 마침 화면 사이에 총 15개 영상 슬라이드가 계획 순서대로 배치됩니다. 각 영상은 슬라이드 진입 즉시 처음부터 재생되고, 발표자가 다음 화면으로 넘길 때까지 현재 슬라이드를 유지합니다.

비공개 작업 저장소에서 공개 가능 여부를 검토한 뒤 필요한 산출물만 이 저장소로 내보냅니다. 이 저장소의 Git 이력만으로 공개 발표를 재현할 수 있어야 합니다.
